## 1. Subgroup：群里面的小群

**定义：Subgroup，子群。**

设 `(G,*)` 是一个群（设集合 `G` 和 星运算 构成了一个群），`H` 是 `G` 的一个子集。如果 `H` 在 `*` 运算下也符合一个群结构，那么称群 `(H,*)` 是群 `(G,*)` 的一个 subgroup 子群，我们用这个类似于小于等于的符号来标记子群 ：

```text
H ≤ G.
```

例如，在整数加法群 `(ℤ,+)` 中，所有偶数构成的集合与加法运算

```text
2ℤ = {...,-6,-4,-2,0,2,4,6,...}
```

就是一个子群。


你可以尝试证明：整数加法群的每一个子群，都可以写成

```text
aℤ = {az : z ∈ ℤ}
```

的形式，其中 `a` 是某个非负整数。

例如：

```text
3ℤ = {...,-9,-6,-3,0,3,6,9,...}
```

就是所有 `3` 的整数倍构成的子群。

魔方群中也有很多子群。

例如，不断重复动作 `R`，会得到一个由四个元素构成的子群：

```text
{e,R,R^2,R^3}.
```

你可以逐条验证，它符合一个群结构。

## 2. Coset：把子群整体搬到别处

我们可以把整个群画成一个很大的区域，把单位元 `e` 画成其中的一个点。

因为任何 subgroup 都必须包含单位元，所以一个 subgroup 可以画成一块包含 `e` 的小区域。

接下来我们要介绍coset陪集的概念，并且说明整个群可以被分割成跟子群同样大小的多个部分。

**定义：Coset，陪集。**

设 `(G,*)` 是一个群，`H≤G`，并且 `a∈G`。

则元素a与子群H中所有元素进行二元运算得到的结果，构成的集合

```text
aH = {a*h : h ∈ H}
```

称为子集 `H` 关于 `a` 的 left coset，左陪集。

类似地，集合

```text
Ha = {h*a : h ∈ H}
```

称为 `H` 关于 `a` 的 right coset，右陪集。我们说 `H` 也是自己的一个 left / right coset ，即 `e*H` / `H*e` 。

先看整数加法群中的例子。取子群

```text
3ℤ = {...,-9,-6,-3,0,3,6,9,...}.
```

把其中每个元素都加上 `1`，得到：

```text
1+3ℤ = {...,-8,-5,-2,1,4,7,10,...}.
```

这就是 `3ℤ` 的一个 coset。

就像我们之前提到的，整数加法满足交换律：

```text
a+b=b+a.
```

满足交换律的群称为 abelian group，阿贝尔群。在 abelian group 中，left coset 和 right coset 总是相等。

但魔方群是一个很好的 non-abelian group 的例子，因为一般来说：

```text
RU != UR.
```

所以魔方群中 `aH` 与 `Ha` 并不一定相等。下面统一使用 left coset 来进行相关的证明；换成 right coset，证明完全类似。

请注意，同一个 coset 可以有很多不同的代表形式。例如：

```text
2+3ℤ = 5+3ℤ = 8+3ℤ
       = {...,-7,-4,-1,2,5,8,11,...}.
```

虽然左侧用了不同的数字来表示，右侧得到的其实是同一个集合。

## 3. Cosets 如何分割整个群

我们接下来证明三个关键事实：

1. 两个 left cosets 要么完全相同，要么完全不相交。
2. 所有 left cosets 覆盖整个群。
3. 每个 left coset 都和 subgroup `H` 包含同样多的元素。

### 3.1 两个 cosets 相等或不相交

**命题：**设 `a,b∈G`。两个 left cosets `aH` 和 `bH` 要么相等，要么不相交。也就是不会出现部分重叠的现象（展示两个圆圈coset部分重合的示意图）

**证明。**

如果 `aH` 和 `bH` 不相交，结论已经成立。

现在假设它们有公共元素。也就是说，存在

```text
x ∈ aH ∩ bH.
```

根据 left coset 的定义，存在 `h1,h2∈H`，使得：

```text
x=a*h1=b*h2.
```

由此得到：

```text
a=b*h2*h1^(-1).
```

任取 `aH` 中的一个元素 `a*h3`，其中 `h3∈H`。代入上面的等式：

```text
a*h3=b*h2*h1^(-1)*h3.
```

因为 `h1,h2,h3` 都属于 subgroup `H`，根据封闭性和逆元性质：

```text
h2*h1^(-1)*h3 ∈ H.
```

所以 `a*h3∈bH`。因此：

```text
aH ⊆ bH.
```

交换 `a` 与 `b`，同理可以证明：

```text
bH ⊆ aH.
```

两个集合互相包含，因此：

```text
aH=bH.
```

命题得证。这也是我们证明两个集合相等的重要手段（判断左边属于右边，且右边属于左边）。

### 3.2 所有 cosets 覆盖整个群

对于任意 `a∈G`，因为 `e∈H`，所以：

```text
a=a*e ∈ aH.
```

因此，群中的每个元素都至少属于一个 left coset。

结合刚才的命题，不同的 cosets 之间又不会发生部分重叠。所以，所有不同的 left cosets 恰好构成 `G` 的一个 partition，分割。

### 3.3 每个 coset 和 H 一样大

考虑映射：

```text
f:H → aH,
f(h)=a*h.
```

我们想说明这是个一一映射，也就是不会出现

```text
a*h1=a*h2,
```

这样就说明两边包含的元素数量相同。

假设上面的式子对于某些 `h1`, `h2` 成立，我们在等式两边左乘 `a^(-1)`，就得到：

```text
h1=h2.
```

所以这个映射是单射。

另一方面，根据 `aH` 的定义，任意 `a*h∈aH` 都是某个 `h∈H` 在这个映射下的像，所以这个映射也是满射。

因此 `f` 是一个 bijection，双射。所以：

```text
|aH|=|H|.
```

不同的 cosets 就像大小完全相同的拼图：它们互不重叠，并且刚好铺满整个群。

## 4. Lagrange's theorem

至此，我们实际上证明完了 Lagrange's theorem，拉格朗日定理。


**定理：Lagrange's theorem，拉格朗日定理。**

设 `G` 是一个 **有限群**，`H≤G`。那么：

```text
|H| ∣ |G|.
```

一个有限群所包含的元素数量，我们也称为这个群的 order，记作：

```text
|G|.
```

这和上一集定义的“群中元素 `g` 的 order”不是同一个概念。群中元素的 order 记作 `ord(g)`。

所以拉格朗日定理也就是说，subgroup 的 order 整除整个 group 的 order。


假设一共有 `k` 个不同的 left cosets，那么：

```text
|G|=k*|H|.
```

这个 `k` 称为子群 `H` 在 `G` 中的 index，指数，记作：

```text
[G:H] = k.
```

这个群比较特殊，它是由一个元素生成的，我们也称这种群为 cyclic subgroup，循环群，记作 `⟨R⟩`。

## 5. 一个实际应用：Thistlethwaite 算法

到这里，coset 和 index 可能仍然显得有些抽象。它们在魔方研究里并不只是为了证明一个整除关系，也可以直接用来压缩计算机需要搜索的状态空间。

20 世纪 80 年代，数学家 Morwen Thistlethwaite 提出了一种计算机求解三阶魔方的方法。它构造了下面这条嵌套的 subgroup chain，子群链：

```text
G0 = ⟨U,D,F,B,R,L⟩
G1 = ⟨U,D,F,B,R^2,L^2⟩
G2 = ⟨U,D,F^2,B^2,R^2,L^2⟩
G3 = ⟨U^2,D^2,F^2,B^2,R^2,L^2⟩
G4 = {e}.
```

这里：

```text
G4 ≤ G3 ≤ G2 ≤ G1 ≤ G0.
```

`G0` 就是完整的三阶魔方群。算法的目标不是一步从 `G0` 走到单位元，而是先进入 `G1`，再进入 `G2`，然后进入 `G3`，最后到达 `G4={e}`。

从 `G0` 进入 `G1` 的第一阶段，固定棱块的朝向。进入 `G1` 之后，后面的动作不再使用 `R`、`L'`、`R`、`L'`，只允许 `R^2` 和 `L^2`，所以已经固定的这部分信息不会再次被破坏。

第二阶段进入 `G2`，进一步固定角块朝向，并把 `FU、FD、BU、BD` 这四个棱块放入相应的 middle slice。

第三阶段进入 `G3`，把棱块放入对应的 slice，把角块限制到两个 tetrads 中，并同时处理相应的 permutation parity 与 twist 约束。

最后一个阶段只允许六个面的半转：

```text
L^2,R^2,F^2,B^2,U^2,D^2,
```

并最终复原魔方。

coset 在这里提供了一种压缩状态的方式。在第 `i` 个阶段，我们不需要区分 `Gi` 中的每一个具体状态，只需要判断它属于 `G(i+1)` 的哪一个 coset。至于使用 left coset 还是 right coset，取决于我们对动作复合方向的约定；两种约定得到的 coset 数量，也就是 index，是相同的。

这四个阶段需要区分的 coset 数量分别是：

```text
[G0:G1] = 2,048,
[G1:G2] = 1,082,565,
[G2:G3] = 29,400,
[G3:G4] = 663,552.
```

反复使用 Lagrange's theorem，就得到：

```text
|G0|
= [G0:G1][G1:G2][G2:G3][G3:G4]|G4|
= 2,048 * 1,082,565 * 29,400 * 663,552
= 43,252,003,274,489,856,000.
```

这正好重新得到完整三阶魔方群的 order。

Thistlethwaite 最初的算法保证最多用 `52` 步复原魔方，这是最早的提供用52步以内步数复原魔方的方法。后来完整计算各阶段的最短路径后，这四个阶段的上界分别可以做到 `7、10、13、15` 步，总共 `45` 步。

但这不等于任意状态的最短解都是 `45` 步，也不等于分阶段分别走最短路径，就一定能得到全局最短路径。它的核心价值，是把一个无法直接穷举的巨大问题，拆成四个可以分别处理的 coset 搜索问题。

这和 CFOP 之类的人类速拧方法有一个相似的直觉：逐步建立结构，并尽量不破坏之前完成的部分。但二者不能直接等同。CFOP 的每个阶段并不天然对应这里的 subgroup chain，也不是依靠 coset lookup table 来求解；Thistlethwaite 主要是面向计算机的算法，而不是让人背诵的速拧公式。

后来 Kociemba 的 two-phase algorithm 延续了相似的思想，把多个阶段合并为两个阶段，并结合搜索与 pruning table，得到更实用的计算机求解器。

## 6. Generated subgroup 与 cyclic group

回到刚才魔方子群的例子：

```text
{e,R,R^2,R^3}.
```

我们称这个子群是由一个元素 `R` 生成的，记作：

```text
⟨R⟩.
```
更准确地说，`⟨R⟩` 是由 `R` 生成的 cyclic subgroup。严谨地写，对于任意 `x∈G`，由 `x` 生成的 cyclic subgroup 是：

```text
⟨x⟩={x^k:k ∈ ℤ}
   ={...,x^(-2),x^(-1),e,x,x^2,...}.
```

如果 `x` 的 order 是有限的，并且：

```text
ord(x)=n,
```

那么：

```text
⟨x⟩={e,x,x^2,...,x^(n-1)}.
```

这 `n` 个元素互不相同。


因此：

```text
|⟨x⟩|=ord(x).
```

现在对 subgroup `⟨x⟩` 使用 Lagrange's theorem：

```text
|⟨x⟩| ∣ |G|.
```

也就得到：

```text
ord(x) ∣ |G|.
```

所以，在任何有限群中，每个元素的 order 都整除整个群的 order。

## 7. 回到魔方：为什么 7 可以，13 不可以

三阶魔方群的 order 是：

```text
|G|=43,252,003,274,489,856,000.
```

它的质因数分解是：

```text
|G|=2^27*3^14*5^3*7^2*11.
```

动作 `R` 的 order 是 `4`，而 `4` 的确整除 `|G|`，符合 Lagrange's theorem。

`13` 没有出现在这个质因数分解中，所以：

```text
13 ∤ |G|.
```

因此，三阶魔方群中不可能存在 order 为 `13` 的元素。

换句话说，不存在一套固定动作，刚好重复十三遍才第一次复原魔方。

但是 `7` 的确整除 `|G|`。我们上段视频结尾错误的说出了不存在 order 为 7 的元素。

不过在三阶魔方群中，order 为 `7` 的元素确实存在。例如，令：

```text
g=B^2 F^2 U B^2 F^2 L^2 D L^2 D' R^2 D R^2.
```

在固定中心位置，并忽略单色中心贴纸自身方向的标准三阶魔方状态模型中：

```text
ord(g)=7.
```

这个动作固定全部棱块和剩下的一个角块，也不改变任何角块或棱块的朝向。它只让另外七个角块循环移动。

这里必须强调我们采用的状态模型：对于普通单色中心贴纸，中心块绕自身法线旋转后，从外观上无法区分，所以标准三阶魔方群通常忽略中心贴纸自身的朝向。在这个标准模型中，`ord(g)=7`。

但是我们后面要使用的字母编号魔方，中心贴纸上的字母具有方向。如果把这些中心字母的旋转方向也计入状态，那么执行 `g` 会改变部分中心贴纸的朝向；在这个更精细的状态模型中，这个具体动作的 order 是 `28`，而不是 `7`。

执行一次，每个角块沿着循环向前移动一个位置；执行两次，就向前移动两个位置。一直执行到第七次，七个角块全部回到起点。

因此：

```text
g^7=e,
```

而：

```text
g,g^2,...,g^6
```

都不等于 `e`。

这就是一个真正的 order 7 元素。它在角块上的作用，是一个 7-cycle。

必须注意，Lagrange's theorem 给出的只是必要条件，不是充分条件。

如果一个整数不整除 `|G|`，它一定不可能成为任何元素的 order；但一个整数即使整除 `|G|`，Lagrange's theorem 本身也没有保证群中一定存在这个 order 的元素。

## 8. 下一集：从 7-cycle 走向 symmetric group

刚才说，这个动作让七个角块形成一个 7-cycle。

这里的“循环”不是比喻，而是一个有严格定义的数学对象。

下一集，我们会给每个 cubie 加上固定标记，引入 symmetric group，对称群，以及 permutation 和 cycle notation。到时候，我们可以直接写出一个动作把哪些方块送到了哪些位置，也可以从 disjoint cycle decomposition 直接读出很多动作的 order。

在之后的盲拧课程中，我们还会重点研究一种特别重要的局部变化：3-cycle。

3-cycle 不是简单交换两个方块，而是让三个方块按照一个方向循环移动，同时保持其他 cubie 的位置与朝向不变。

这正是三阶魔方盲拧中非常核心的操作之一。

我们会进一步介绍 commutator，交换子，说明怎样利用动作和逆动作之间的大量抵消，构造出一个只影响少数 cubie 的 3-cycle。
