## Definition 1: Group

群是什么？

群是一些元素的集合，所谓的元素可以是数字、魔方、台球等任何事情。加上定义在这个集合上的一个二元运算 (binary operation)，我们用星号来表示。

```text
* : G × G -> G.
```

意思是，对于集合中任意两个元素，通过运算我们得到唯一的一个元素。

比如所有整数构成的集合，与加法运算。

如果这个集合与二元运算符合下面四条公理，我们就称它们 (G , *) 为一个群。

公理一，closure，封闭性。

对于任意 `a, b ∈ G`，

```text
a * b ∈ G.
```

经过运算，结果仍然留在集合中。比如两个整数加起来还是一个整数。

公理二，associativity，结合律。

对于任意 `a, b, c ∈ G`，

```text
(a * b) * c = a * (b * c).
```

进行连续运算时，首先进行第一个运算，与首先进行第二个运算，得到的结果是一样的。

比如 `(1 + 2) + 3 = 1 + (2 + 3)` 。

公理三，identity element，单位元。

集合中存在一个元素 `e ∈ G`，使得对于所有 `a ∈ G`，

```text
e * a = a * e = a.
```

就像整数中的 `0` 。任何整数加上 `0` 还等于它自己，对吧？

公理四，inverse，逆元。

对于每个 `a ∈ G`，都存在一个元素 `a^(-1) ∈ G`，使得

```text
a * a^(-1) = a^(-1) * a = e.
```

比如 `7 与 -7` 。

可以看到，对于整数与加法运算，符合上面的四条定理，所以这是一个群结构，我们叫整数加法群。但对于整数与乘法运算，就不符合一个群结构，你能说出来哪里不符合么？

## Cube notation

群结构是一个非常有力的工具，可以帮我们理解世界上的很多事情，包括魔方。

在严谨定义魔方群之前，我们先统一下这系列视频使用的记号。

一个三阶魔方可以看成由许多小块组成。这些小块称为 方块 cubies。

其中有 8 个 角块 corner cubies；12 个 棱块 edge cubies；以及 6 个 中心块 center cubies。

我们固定各中心块的朝向，并用大写字母表示魔方的六个面：

```text
U: up
D: down
L: left
R: right
F: front
B: back
```

用小写字母标记具体的 方块 cubies。

例如：

```text
urf
```

表示同时位于 up、right、front 三个面的角块。

```text
ur
```

表示位于 up 和 right 两个面的棱块。

我们也用大写字母表示转动动作。

比如 `R` 表示把魔方的右面顺时针旋转 90 度。

逆时针旋转记作：

```text
R^(-1),
```

我们也经常写作：

```text
R'. (R prime)
```

旋转一个面两次，即 180 度记作：

```text
R^2.
```

在整个系列视频中，我们按照从左到右的顺序执行动作。

例如：

```text
U D F
```

表示先做 `U`，再做 `D`，最后做 `F`。

这个约定很重要，因为魔方动作通常不满足交换律 commutativity。我们进行 右上 RU 与 上右 UR 动作得到不同结果

```text
R U != U R.
```

## Definition 2: The Rubik's Cube Group

现在我们严格定义三阶魔方群。

由六个基本面旋转动作

```text
U, D, L, R, F, B
```

以及它们的逆动作，可以组成任意有限长度的序列，比如 `UFD'L^2B` ，我们称其为一个 `动作序列`。

请注意，写法不同的 `动作序列` 可能对应相同的最终魔方状态。

例如：

```text
R'
```

和

```text
R^3
```

或者

```text
LR
```

和

```text
RL
```

我们认为这两组 `动作序列` 在魔方群中分别只代表同一个元素，是等价的。

那我们定义，

魔方群就是这些等价的 `动作序列` 的集合。魔方群上的运算就是自然的按照先后顺序结合两个 动作序列。

例如：

```text
UF * LB = UFLB
```

我们需要验证它确实符合群的四条公理。

1. closure 封闭性

任意两个 动作序列，结合起来仍然是一个动作序列

1. associativity 结合律

对于三个动作序列的连续运算，先结合前面两个，或者后面两个，得到的结果是一样的。因为根据定义，我们最底层执行的操作都是一样的。

```text
(RD * L'FD) * F^2L = RD * (L'FD * F^2L) = RDL'FDF^2L
```

1. identity element 单位元

什么都不做的动作序列就是魔方群中的单位元，或者你也可以说右侧转四下、右侧转一下再转回来。他们都是等价的，不是么？

1. inverse 逆元

对于任意一个动作序列，如 `FD'R` ，我们取每个动作的逆动作并反向组成一个序列，这里就是 `R'DF'` ，则可以验证，它就是原始动作序列的逆元：

`FD'R * R'DF' = R'DF' * FDR' = e`

所以我们上面定义的三阶魔方群确实符合一个群结构。可以看到，这个群中的元素与三阶魔方状态是一一对应的。

## Theorem: Repetition in a finite group

经过前面这些麻烦的定义，我们现在可以品尝一些甜美的果实了。回到开头的问题，我们有下面定理：

**定理 1.1：**

设 `(G, *)` 是一个有限群，也就是群中的元素数量是有限多个，且 `g ∈ G`。

那么存在一个正整数 `n`，使得

```text
g^n = e.
```

也就是在魔方群中，任意一个动作序列，重复一定次数将会回到原始状态。

**Proof.**

假设有限群 `G` 一共有 `N` 个元素。

考虑下面 `N + 1` 个群元素：

```text
e, g, g^2, ..., g^N.
```

整个群中一共只有 `N` 个元素，但这里列出了 `N + 1` 项。那么其中至少有两项相等。

因此，存在不同的整数 `i,j`，满足

```text
0 <= i < j <= N
```

并且

```text
g^i = g^j.
```

根据群的定义，每个元素都有一个inverse逆元，在等式两边同时左乘 `g^(-i)`：

```text
g^(-i) * g^i = g^(-i) * g^j.
```

左边等于单位元 `e`，右边等于 `g^(j-i)`，所以：

```text
e = g^(j-i).
```

因为 `j` 大于 `i`，所以我们已经找到了一个正整数 `n=j-i`，使得

```text
g^n = e.
```

定理得证。

```text
Q.E.D.
```

---

可以看到这个证明的关键，首先是对于一个有限群，如果像整数加法群那样，对于数字1，一直加1加1，最终也不会等于0，对吧？还有就是，因为符合群结构，每个元素都有其逆元。

那么魔方群是有限群么？如果学过一点排列组合的知识，就知道，对于8个角块，一共有8！种排列方式，每个角块有三种旋转方式，所以要再乘以 3^8 。同样的对于棱块有12！种排列方式，再乘以 2^12 。但这其中有一些情况不符合实际，比如把一个角块拽出来再拧一下。所以我们需要再除以一些数字。我们需要更多的群论知识来严谨证明它。

## Definition 3: Order of an element

那很自然的，我们想知道魔方中的动作都重复多少次能够复原。这里我们引入元素的 order 的概念。

设 `(G, *)` 是一个群，`g ∈ G`。

如果存在正整数 `n` 使得

```text
g^n = e,
```

那么所有满足这个等式的正整数 `n` 中，最小的一个称为 `g` 的 order，记作：

```text
ord(g).
```

如果不存在这样的正整数，则称 `g` 具有 infinite order。

比如魔方群中 R 的四次方、八次方、十二次方都等于单位元 e，其中 4 是这些正整数中最小的，则我们说 `ord(R)=4` 。

又比如，在整数加法群 `(Z,+)` 中，任意非零整数都具有 infinite order。

## Back to the Rubik's Cube

现在，回到视频开始的列表，我们可以更严谨的说，在魔方群中，这些元素的order是这些数字。

## 数学与制作备注

- 本集采用 Janet Chen 讲义中的执行顺序：`M1 M2` 表示先做 `M1`，再做 `M2`。后续课程必须保持同一约定。
- 大写 `U,D,L,R,F,B` 表示 moves；小写 `urf`、`ur` 等表示 cubies 或 cubicles。
- 本集严格区分 move sequence 与 transformation。群元素是 transformation，而不是书写动作的字符串。
- `R^(-1)=R^3`，但 `R` 与 `R^3` 不是同一个群元素。
- 群元素与合法状态的一一对应依赖于固定复原状态、固定中心位置，并排除整体旋转魔方造成的观察坐标变化。
- 定理先证明存在正整数 `n` 使 `g^n=e`，随后再定义满足该式的最小正整数为 `ord(g)`。
- 本集不定义 subgroup、cyclic subgroup 或 coset，也不陈述或证明 Lagrange's theorem。
- `ord(RU)=105` 使用本课程从左到右执行的记号约定，并采用普通魔方的状态模型：中心块位置固定，单色中心贴纸自身的旋转角度不计入状态。
- 如果画面使用带方向的中心 Logo，`cubing.js` 的 supercube 状态模型会把中心朝向也计入，此时 `RU` 的完整周期是 `420`。本集动画应使用纯色中心贴纸，或在计算和渲染时忽略中心朝向。
